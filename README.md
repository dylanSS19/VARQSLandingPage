# Proyecto Constructora - Modelos Arquitectónicos de Casas

Página web para una empresa de construcción y creación de modelos arquitectónicos en casas.

## Estructura del proyecto

```
proyecto-constructora/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
└── assets/
    ├── images/
    └── icons/
```

## Cómo usar

1. Abre `index.html` en tu navegador.
2. Agrega imágenes de tus proyectos en `assets/images/`.
3. Personaliza los textos y colores en `css/style.css`.
